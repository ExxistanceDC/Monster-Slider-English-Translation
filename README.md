## **Patching Instructions**

The patch is shipped as an XDelta patch. 

### XDelta Instructions ###

1. Grab an XDelta patching utility like <a href='https://www.romhacking.net/utilities/704/'>Delta Patcher</a>
2. Unzip patch bundle
3. Open **'DeltaPatcher.exe'**
4. For the Original File, locate Track 01 of the original Monster Slider disc (for example: <kbd>Monster Slider (Japan) (1M) (Track 01).bin</kbd>)
5. For the XDelta patch section, locate the <kbd>Monster_Slider_English_Translation_v1.0.xdelta</kbd> patch.
6. Click **'Apply Patch'**
7. If successful, Track 01 will be replaced with the patched track.

**--> Important! <--**
- Tested with release <kbd>Monster Slider (Japan) (1M)</kbd>
- Tested on emulators Ymir/Mednafen, and real hardware with Satiator.
